# AI 强化设计与验证

本文记录电脑对手的决策原则、公开信息边界与可复现评测方法。策略依据来自实战解说、五色高分流、开场战术、进化组合及「黄色高分牌」资料；实现只使用归纳后的规则，不依赖字幕名称匹配卡牌，实际动作始终以卡牌数据库的 `id/cost/bonus/vp/evolvesTo` 为准。

## 决策目标

AI 的首要目标是用更少的个人行动达到完整胜利条件，而不是单纯堆积原始分数：

- 基础/PokéMart：达到 18 分并处理最后一轮座次。
- Mega：达到 20 分、集齐五色、拥有至少一只 Mega，三项缺一不可。
- 一回合只允许一次普通或 Mega 进化；主动作、弃球、进化与结束回合必须作为同一条计划评估。

## 已落地且通过 A/B 的规则

1. **完整扩展动作空间**
   - 图鉴：比较消耗 1–N 张图鉴后的可购买目标；PokéMart + Mega 中，即使主卡本来买得起，也会比较「弃图鉴保留大师球，并在同回合完成 Mega」的完整路线。
   - TM/神奇糖果：按实际奖励色比较关联对象。
   - 进化石/神奇糖果：递归枚举合法免费取卡链。
   - 驱虫喷雾：优先保留高分、稀有、双奖励及可进化核心牌，再限制组合宽度。
   - Mega：把拿代币、普通进化、Mega 进化放进同一回合计划。

2. **实战战术**
   - 对手下一回合若能「购买 + 进化」达到 18 分，显著提高抢牌/保留的阻断价值。
   - 对攻略中反复验证的协同组合只提供小幅平手分，例如杰尼龟+独角虫、小火龙+尼多兰、凯西+喇叭芽；核心牌消失后不会强锁路线。
   - 直接模拟 `endTurn`，能结束时优先结束，并正确识别最后一轮结果。
   - Mega 模式奖励五色覆盖；能完成完整条件时直接收官。普通进化若能到达仍在供应区的 Mega 对应终形，后期获得温和路线加分。
   - 同回合只能进化一次：第一条待进化路线保留完整价值，第 2 条起按队列折扣，避免把多只同时就绪的宝可梦误算成同回合全部得分；Mega 模式暂不启用此折扣。
   - 最后一轮已经开始后，不再把「对手跨过触发分数」当作可以提前结束游戏的即时威胁，改由正常分数与阻断估值处理。

3. **公开信息与稳定性**
   - hard AI 从面牌、公开牌、筹码、牌堆数量和自己的留牌构造 4 份稳定的信息集样本并取平均。
   - 对手留牌身份与真实牌堆顺序不会进入决策；反转所有暗牌后，行动保持不变。
   - 究极搜索使用独立固定 RNG，相同局面与配置重复运行得到相同计划。
   - 搜索遇到无合法主动作的内部节点会执行强制跳过，不再崩溃。

## 被评测否决的实验

以下规则听起来合理，但当前实现方式在固定种子对战中退步，因此没有保留：

- 全局大幅奖励「未来可能有用的底色」：会让 3–4 人局过度铺色、路线过长。
- 对不可见进化牌统一给予较高期望值：容易追逐尚未翻出的链条。
- 严格惩罚免费零分牌：三人局会过早放弃仍可转型的路线。
- 对所有进化排队施加固定惩罚：会压低本来就有价值的下一回合免费进化。
- 对每个候选动作完整展开所有对手的一回合终局：组合扩展四人局曾达到 P95 142 ms、最大 529 ms，默认 UI 不接受。
- 只计算一次公共威胁再奖励抢牌：432 局换座 A/B 没有净胜率提升，并在混合难度 Mega 四人局触发 1 个资源耗尽死局，因此未启用。
- 究极难度的完整最终轮推演：60 simulations / 2 determinizations 下为 10/20（50%），且评测达到 4.76 秒/整局；200/3 的直接评测成本更高，继续保持关闭。

这些原则以后可以通过更短的终局阵容搜索重新引入，但不应再用全局常数直接叠加。

## 固定种子 A/B

评测让新版 AI 对战冻结的旧版部署逻辑。每个 seed 都把候选 AI 轮换到全部座位，因而同时控制牌序与先后手。32 blocks 用于基础/PokéMart/Mega，组合扩展使用 16 blocks，共 1008 局：

| 模式 | 新版胜场 | 公平预期 | 归一化表现 |
|---|---:|---:|---:|
| 基础 | 111 / 288（38.54%） | 33.33% | 1.156× |
| PokéMart | 144 / 288（50.00%） | 33.33% | 1.500× |
| Mega | 123 / 288（42.71%） | 33.33% | 1.281× |
| PokéMart + Mega | 85 / 144（59.03%） | 33.33% | 1.771× |
| 总计 | 463 / 1008（45.93%） | 33.33% | 1.378× |

全部对局为固定种子、全座位轮换；非法动作 0，未结束对局 0。九个基础矩阵单元中最慢的平均 hard 决策为 9.53 ms。

### 第二轮增量验证

这一轮只比较单一开关，双方均使用同一版 hard AI，并按 seed × 全座位轮换：

| 改动 | 模式 | 候选胜场 | 公平预期 | 结论 |
|---|---|---:|---:|---|
| 进化队列折扣（开发 + holdout） | 基础 | 115 / 324 | 108 / 324 | +7 胜，两个种子组方向一致 |
| 进化队列折扣（开发 + holdout） | PokéMart | 108 / 324 | 108 / 324 | 持平 |
| 最终轮威胁修正 | 基础 + PokéMart | 143 / 432 | 144 / 432 | 统计持平，保留规则修正 |
| 主动图鉴保大师球 | PokéMart + Mega | 48 / 144 | 48 / 144 | 全局持平；固定局面验证能新增合法同回合 Mega 胜路 |

组合扩展四人局的主动图鉴性能抽样（6 个固定种子、696 次决策）：平均 10.06 ms、P95 23.41 ms、最大 59.02 ms，与关闭时的 10.36 / 22.78 / 57.60 ms 相当。
